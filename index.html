SERVICES

Full-Stack Web Development

I build responsive, production-grade web applications end to end — interface, application logic, and backend — using HTML, CSS, JavaScript, React, and PHP. That means thinking about the database schema and the server-side logic at the same time as the interface, so the two don't fight each other later. I care about pages that load fast, forms that fail gracefully, and architecture that doesn't need to be rebuilt the first time real traffic hits it.

Mobile Application Development

I design and build cross-platform mobile applications in Flutter, backed by Firebase for authentication, real-time data synchronization, and cloud storage. The goal isn't just feature parity across iOS and Android — it's an interface that respects how people actually hold and use their phones: fast interactions, minimal friction, and state that persists correctly when the app is backgrounded, killed, or reopened on a bad connection.

Data Analytics & Dashboard Design

I take raw, inconsistent datasets and turn them into dashboards that answer one specific business question well, rather than displaying every metric available. That starts with data cleaning — the unglamorous but decisive part of the work — and ends with a Tableau dashboard built around how a decision-maker actually reads a chart under time pressure.

UI/UX Prototyping

I build wireframes and interactive prototypes in Figma before a single line of production code is written, so design decisions get tested cheaply — on a click-through prototype — instead of expensively, after the interface is already built.
